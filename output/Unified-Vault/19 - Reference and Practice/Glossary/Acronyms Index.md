This index expands the acronyms used across AI engineering — optimizers, architectures, benchmarks, serving infrastructure, and alignment methods. Each entry gives the expansion and, where a dedicated note exists, links to the relevant concept note for the full treatment. Entries are grouped letter by letter from A to Z. For full term definitions see [[A-Z Terms]]; for mathematical symbol conventions see [[Notation Conventions]].

## A

Optimizers, attention variants, quantization methods, and testing vocabulary open the index.

- **Adam** — Adaptive Moment Estimation. See [[Optimization Essentials]]
- **ADAMW** — Adam with Weight Decay. See [[Optimization Essentials]]
- **AGI** — Artificial General Intelligence
- **AISI** — AI Safety Institute (UK)
- **ALiBi** — Attention with Linear Biases. See [[ALiBi]]
- **ANN** — Approximate Nearest Neighbor (vector search algorithm)
- **API** — Application Programming Interface
- **ASR** — Automatic Speech Recognition. See [[Whisper]]
- **AWQ** — Activation-aware Weight Quantization. See [[Quantization]]
- **A/B Testing** — split testing. See [[A-B Testing and Shadow Deployment]]

## B

The B entries are dominated by model families and retrieval baselines.

- **BART** — Bidirectional and Auto-Regressive Transformers. See [[T5 and BART]]
- **BBH** — BIG-Bench Hard (benchmark)
- **BERT** — Bidirectional Encoder Representations from Transformers. See [[08 - Attention and Transformers/Transformer Architecture/BERT|BERT]] (concept) and [[17 - Papers/Attention and Transformers/BERT|BERT]] (paper)
- **BM25** — Best Matching 25 (keyword search). See [[BM25]]
- **BPE** — Byte-Pair Encoding. See [[BPE]]

## C

The C entries cover embeddings, prompting, corrective retrieval, and GPU programming.

- **CBOW** — Continuous Bag of Words (Word2Vec variant). See [[Word2Vec GloVe and FastText]]
- **CLIP** — Contrastive Language-Image Pre-training. See [[CLIP]]
- **CoT** — Chain-of-Thought. See [[Chain of Thought]]
- **CRAG** — Corrective RAG. See [[Advanced RAG Patterns]]
- **CUDA** — Compute Unified Device Architecture (NVIDIA GPU programming)

## D

The D entries span clustering, diffusion models, preference optimization, and reinforcement learning.

- **DBSCAN** — Density-Based Spatial Clustering of Applications with Noise
- **DDIM** — Denoising Diffusion Implicit Models
- **DDPM** — Denoising Diffusion Probabilistic Models
- **DeiT** — Data-efficient Image Transformer
- **DPO** — Direct Preference Optimization. See [[DPO]] (paper) and [[DPO Derivation]]
- **DQN** — Deep Q-Network. See [[Q-Learning and Deep Q Networks]]

## E

The E entries cover contextual embeddings and evaluation.

- **ELMo** — Embeddings from Language Models. See [[Contextual Embeddings ELMo to BERT]]
- **ELECTRA** — Efficiently Learning an Encoding that Classifies Token Replacements Accurately
- **EVAL** — Evaluation (model benchmarking)

## F

The F entries mix embedding methods, the Transformer feed-forward sublayer, and distributed-training and precision vocabulary.

- **FastText** — Facebook's word embedding method. See [[Word2Vec GloVe and FastText]]
- **FFN** — Feed-Forward Network. See [[Feed-Forward Network]]
- **FLOPs** — Floating-Point Operations
- **FSDP** — Fully Sharded Data Parallel. See [[Distributed Training]]
- **FP8/FP16/FP32** — Floating Point (8/16/32-bit precision)

The G entries cover activations, model families, file formats, attention variants, and optimizers.

- **GELU** — Gaussian Error Linear Unit. See [[Activation Functions]]

- **GGUF** — GPT-Generated Unified Format (model file format). See [[Ollama and llama.cpp]]

The H entries cover vector indexing and the model hub.

- **HNSW** — Hierarchical Navigable Small World (vector index)

The I entries cover in-context learning, preference optimization, and vector indexing.

- **ICL** — In-Context Learning. See [[In-Context Learning]]
- **IPO** — Identity Preference Optimization
